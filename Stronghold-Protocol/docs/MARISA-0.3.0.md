# 魔理沙 MOD · Stronghold-Protocol 0.3.0

用户已完成本机游玩验收。本版将魔理沙 MOD 管理器和玩法迁入原版 0.3.0 的原生插件系统，保留四名干员、罗德岛、鲲、驻防、皮肤与形态、自选候选和单场回放。本页与适配代码使用 AI 辅助整理。

## 安装和启动

- **完整包**：解压到新目录，包含程序、生产依赖、前端库和本机已准备的游戏素材；需要 Node.js 22 或更新版本。Windows 双击 `scripts/start-marisa.cmd`，其他系统运行 `SP_PLUGIN_SCRIPTS=sandbox node scripts/launch.mjs --no-setup --host 127.0.0.1`。
- **兼容替换包**：只用于未修改的原版 0.3.0。停止服务并备份后，将包内 `Stronghold-Protocol/` 的内容合并覆盖原安装，保留原有素材。包含兼容程序、依赖、插件及追加素材；不是跨版本自动更新包，不适用于旧 MOD 或其他游戏版本。
- **单独插件包**：`marisa-0.3.0.zip` 使用原版插件格式，安装到 `plugins/marisa/`。必须先安装本版兼容补丁；单独放进未修改原版 0.3.0 不能保留全部功能。完整包和兼容替换包已经安装此插件，无需重复安装。

再次双击启动脚本会复用正在运行的游戏并打开页面；关闭网页不会停止服务。在首次启动的服务窗口按 Ctrl+C 可停止。不要同时启动多个服务争用 3000 端口。

## 在哪里配置 MOD

1. 创建房间，点击房间顶部的“插件”标签。
2. 开启“魔理沙追加 MOD”，在其管理器中展开分类。
3. 点击“应用设置”，等待插件内容就绪后开始对局。

管理器保留已有干员原版/MOD 切换、追加干员启停和商店/V、VI 阶自选路线、罗德岛及原版盟约新增成员、鲲策略等配置。结城理、医疗阿米娅进入自选后不再进普通商店，同一追加角色跨 V/VI 阶只能编入一个位置。明确的成员选择优先于干员模式；盟约总开关关闭时成员不生效。干员装备模组偏好保持独立。加入者、观战者和重连者使用房主的原生内容配置与哈希。

## 兼容补丁范围

原版 0.3.0 的接口不足以直接表达全部旧 MOD。本版补充新增盟约命名空间、声明式配置合成、脚本效果及召唤物分发、完整数据视图、整备期叠层来源和范围、自选互斥、形态/皮肤与起飞显示。脚本仍使用原版内容哈希、锁验证、SES 沙箱和执行预算。

脚本启动超时、进程异常或缺失报告不再永久缓存为“不兼容”，相同设置可重新应用；显式脚本错误仍被拒绝和缓存，超时进程仍被终止。

## 开发与验证

可读脚本来源与生成入口在 `mods/marisa-native/`，可安装产物在其 `bundle/marisa/`。安装插件：将该文件夹复制到 `plugins/marisa/`。重建需先在 `mods/marisa-native/` 安装其开发依赖，再运行构建脚本；修改文件后运行 `node tools/plugin.mjs check marisa --strict`、`node tools/plugin.mjs test marisa` 和 `node tools/plugin.mjs pack marisa --zip`。正式打包入口为 `node tools/package-marisa.mjs`。

本地单场测试：

```powershell
node tools/mod-test.mjs --scenario kun-wave --stage act1autochess_m01 --round 2 --difficulty HARD --operator 乌尔比安 --skill 1 --seed 27 --seconds 40
```

回放页面：`http://127.0.0.1:3000/dev/render-demo.html?scene=mod-test&board=2d`。测试生成文件不提交 Git；再次运行会覆盖回放。测试资金默认关闭，设置 `SP_DEV_FUNDS=9999` 后仅在启用此插件的单人、人类席位按正常收入通道补足。

保留原 MOD 的自创规则，包括结城理人格面具形态、追加商店/驻防/盟约规则及凯尔希自创技能开放方式；这些不是官方模式平衡承诺。来源为上游 v0.3.0（c24e17eec3af1e6dedfa9935a6d15245cf2f4586）及原魔理沙 MOD 的已适配源码。可选本地 3D 场景缺失时使用默认棋盘。
